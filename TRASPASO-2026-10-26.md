## C. Cómo usar los scripts de `tools/`

Reglas comunes:
- Ejecutar con `python3 -I tools/<script>.py` (Python 3.9 del sistema). **Dry-run por defecto** (solo lee); `--apply` escribe; `--rollback <copia> --apply` restaura.
- Las copias previas van a `_backup/` (en `.gitignore`: no se sube). Cada `--apply` relee y comprueba el resultado.
- Auth: client credentials de la app "HumindIA Analytics". Keychain, cuenta `shopify-casamaravillas`, servicios `shopify-admin-client-id` y `shopify-admin-client-secret`; tienda `jbtugu-s0.myshopify.com`.
  Todos los scripts nuevos importan la auth de `shopify_update_precios_embutido.py`. **Los scripts antiguos** (`shopify_update_ingredients*.py`, `shopify_update_jamones_enteros.py`, `shopify_update_loncheados.py`) buscan otra cuenta/servicios del Keychain y otro dominio: no autentican tal cual.
- La API Admin solo tiene `read_themes`: los temas se tocan con el CLI de Shopify (hay sesión iniciada) vía `shopify_paso5_tema.sh`.
